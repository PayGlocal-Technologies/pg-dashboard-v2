# Feature Tracker (pg-dashboard-v2)

This is the shared list of design work in flight. The "Publish" script adds a row here
automatically when a designer finishes a feature. Engineering reads this list to know what
is ready to integrate.

Status meaning:
- **In design** - a designer is still building it.
- **Ready for integration** - design is done and pushed. Engineering can pick it up.
- **Integrating** - an engineer is wiring up the backend.
- **Done** - merged into uat.
